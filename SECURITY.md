# Security Policy

## Supported Versions

Currently, only the latest `main` branch of NetPay KE is supported with security updates.

## Reporting a Vulnerability

Security is very important to us. Since this is a client-side calculator, vulnerabilities typically involve XSS or other frontend issues.

If you discover a security vulnerability within NetPay KE, please do not disclose it publicly. Instead, send an email to the repository maintainers or create a confidential security advisory through GitHub.

Please include:
- A description of the vulnerability.
- Steps to reproduce the issue.
- The browser and operating system where it occurs.

We will review the issue and aim to address it as quickly as possible.
