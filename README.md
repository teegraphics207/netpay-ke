# NetPay KE

**NetPay KE** is an open-source Kenyan salary and payroll calculator designed to help employees, HR teams, accountants, students, freelancers, and small businesses estimate salary deductions and net pay clearly.

The project aims to make Kenyan payroll calculations easier to understand by showing deductions such as PAYE, NSSF, SHIF/SHA, Housing Levy, and other common salary deductions in a simple, user-friendly interface.

> ⚠️ Disclaimer: This tool is for educational and estimation purposes only. Kenyan tax and payroll rules may change. Always verify final payroll figures with KRA, SHA, NSSF, or a qualified payroll/accounting professional.

## Key Features

- Estimate gross salary to net salary.
- Calculate common Kenyan payroll deductions.
- Show a simple breakdown of deductions.
- Useful for employees, HR teams, students, and small businesses.
- Clean, responsive UI for desktop and mobile users.
- Open-source and community-friendly.

---

## Why This Project Matters

Many Kenyan workers and small businesses struggle to understand how salary deductions affect take-home pay. NetPay KE provides a clear, transparent, and accessible way to estimate payroll deductions and improve financial awareness.

This project can support:

- Employees checking their expected net pay.
- HR teams explaining salary deductions.
- Students learning payroll and taxation basics.
- Small businesses estimating staff costs.
- Developers contributing to civic and financial technology tools.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/teegraphics207/netpay-ke.git
cd netpay-ke
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

### 4. Build for production

```bash
npm run build
```
