# Contributing to NetPay KE

Thank you for your interest in contributing to **NetPay KE**.

This project exists to make Kenyan salary and payroll calculations easier to understand. Contributions that improve accuracy, usability, accessibility, documentation, and code quality are welcome.

---

## Ways You Can Contribute

You can contribute by:

- Reporting calculation errors.
- Suggesting improvements to payroll logic.
- Improving the user interface.
- Fixing bugs.
- Adding tests.
- Improving documentation.
- Reviewing code.
- Creating educational content around Kenyan payroll deductions.

---

## Before You Start

Please check existing issues first to avoid duplicate work.

If you want to make a large change, open an issue first and explain:

- What you want to change.
- Why the change is useful.
- How you plan to implement it.

---

## Local Setup

### 1. Fork the repository

Click **Fork** on GitHub.

### 2. Clone your fork

```bash
git clone https://github.com/YOUR-USERNAME/netpay-ke.git
cd netpay-ke
```

### 3. Install dependencies

```bash
npm install
```

### 4. Run the project locally

```bash
npm run dev
```

---

## Pull Request Guidelines

Before opening a pull request:

- Make sure the app runs without errors.
- Keep your changes focused.
- Use clear commit messages.
- Explain what your pull request changes.
- Add screenshots for UI changes.
- Add tests where possible.

---

## Calculation Accuracy

Payroll rules can change. If you are updating tax or deduction logic, please include a source or explanation for the rule change.

Examples:

- PAYE bands
- Personal relief
- NSSF rates
- SHIF/SHA deductions
- Housing Levy
- Other statutory deductions

---

## Code Style

Please keep the code:

- Clear
- Readable
- Well-commented where necessary
- Beginner-friendly

---

## Community Standards

Be respectful and constructive. This project is meant to help people learn and understand payroll better.
